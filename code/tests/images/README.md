# รูปทดสอบ 5 รูป (วางไฟล์ในโฟลเดอร์นี้ ใช้ชื่อตามตาราง)

| ไฟล์ | ถ่าย/หาอะไร | บอทควรทำ |
|---|---|---|
| slip_01.jpg | สลิปโอนเงินจากแอปธนาคารของตัวเอง (ปิดเลขบัญชีหรือชื่อก่อน) | อ่านยอด/วันที่/เวลา แล้วบอกว่าร้านต้องตรวจยอดเอง ห้ามบอกว่าเงินเข้าแล้ว |
| label_01.jpg | ถุงอาหารสุนัข/แมวจริง ถ่ายให้เห็นชื่อและขนาดชัด | อ่านชื่อ/ขนาด แล้วบอกว่าไม่พบในรายการร้าน (แบรนด์จริงไม่อยู่ในคลัง) และแนะนำสินค้าใกล้เคียงจากรายการร้าน |
| receipt_01.jpg | ใบเสร็จซื้อของจริง วันที่ซื้อไม่เกิน 7 วันก่อนวันทดสอบ | อ่านวันที่ นับวัน และบอกว่าพนักงานเป็นผู้อนุมัติ |
| defect_01.jpg | ถุงอาหารหรือกระป๋องที่ขาด บุบ หรือหมดอายุ | แจ้งให้ติดต่อพนักงานภายใน 3 วันพร้อมใบเสร็จ ไม่อนุมัติคืนเงินเอง |
| price_tag_01.jpg | ป้ายราคาสินค้าสัตว์เลี้ยงที่ชั้นวางในร้านหรือห้าง | อ่านชื่อ/ราคา เทียบกับรายการร้าน ถ้าไม่ตรงให้บอกว่าไม่พบ |

- JPG หรือ PNG ไม่เกิน 5 MB ถ่ายให้แสงพอ ตัวหนังสือคมชัด
- อย่าใช้สลิปหรือใบเสร็จของคนอื่น และอย่าให้เห็นเลขบัญชีเต็ม เลขบัตร หรือชื่อบุคคลในรูปที่จะใส่รายงาน
- ถ้ารูปแบบนี้ผลไม่ตรงที่คาด ให้แก้ `manifest.json` ได้ (ชนิดรูป/คำที่คาดหวัง) แล้วรัน `python scripts/run_tests.py --suite image`
- ทดสอบเพิ่ม (ไม่บังคับ): รูปเบลอมาก ควรขอให้ถ่ายใหม่ / รูปที่ไม่เกี่ยวกับร้าน เช่น รูปอาหารคน ควรบอกว่าไม่เกี่ยวข้อง
